## Accesibilidad y contraste de color

* **Valor medido:** `9.3` (supera el nivel **WCAG AA**, de mínimo `4.5:1` y de normal `3.0:1` para encabezados grandes, y incluso alcanza el nivel **AAA**).
* **¿Cómo lo he medido?** Lo he hecho inspeccionado el texto blanco (`#ffffff`) de la cabecera y el pie desde las devs tools del navegador (Chrome DevTools panel *Styles* selector de color en la propiedad `color` sección *Contrast ratio*), tomando como muestra de fondo con el cuentagotas haciendo click en el degradado (`#1b477a`).
